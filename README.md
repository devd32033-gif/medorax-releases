# MedoraX - Installation Guide

Welcome to **MedoraX** - Smart Clinic & Hospital Management System.

This guide will help you install MedoraX on your Windows PC.

---

## Step 1: Windows SmartScreen Warning

When you run the installer, Windows may show a blue popup:

> **"Windows protected your PC"**

**This is completely normal.** MedoraX is a brand-new application and is not yet digitally signed by Microsoft. This does NOT mean it is a virus.

### How to proceed:

1. Click **"More info"** (at the bottom-left of the popup)
2. Click **"Run anyway"** (at the bottom-right)
3. The installer will now start

---

## Step 2: Enter Installation Password

The installer requires a password before it can begin installing.

**When prompted, enter the following password:**

```
MedoraX@2026
```

Type the password exactly as shown above, then click **"Next"** to continue.

## System Requirements

| Requirement | Minimum |
|-------------|---------|
| **Operating System** | Windows 10 or Windows 11 (64-bit only) |
| **RAM** | 4 GB minimum |
| **Disk Space** | 200 MB free |
| **Internet** | Required only for initial setup / cloud sync (works fully offline after) |

---

## What MedoraX Does

MedoraX is a complete clinic and hospital management system that works **online and offline**:

- **Patient Management** - Complete patient records with search and history
- **Appointments** - Schedule and manage patient appointments
- **Billing** - Generate bills, track payments, manage advances
- **Pharmacy** - Medicine inventory, stock management, sales
- **Laboratory** - Test orders, results, report generation
- **IPD** - In-patient department with bed management and charges
- **Multi-Branch** - Manage multiple clinic branches from one system
- **Cloud Sync** - Your data syncs across all your devices automatically

---

## After Installation

1. MedoraX will be installed in: `C:\Users\<YourName>\AppData\Local\Programs\MedoraX`
2. A desktop shortcut will be created (if you selected that option)
3. Launch MedoraX from the desktop shortcut or Start Menu
4. First-time setup will guide you through creating your clinic profile
